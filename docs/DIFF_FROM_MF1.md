# Отличия от первой «Фермы Айрис»

Сравнение данных: «Цветок Стихий» (`original/install`, `original/pak`) против первой игры
(`CrossOver/Bottles/Farm/drive_c/Program Files/Game0` — источник порта `Farm`). Только по данным,
exe ещё не разбирался.

## Объём

- Файлов ресурсов: 3003 против 1046. Старые ресурсы все на месте (из 1046 нет 13 — переименования), остальное добавлено.
- `game.exe` — сама игра (строки `vegetation`, `bouquet_price_k`, `auto_bouquet_level`…), 5,6 МБ против 2,8 МБ у `Magic Farm_fixed.exe`.
- Логика вынесена в `xml/properties.xml` (250 КБ), интерфейс — в `xml/properties_ru.xml`; тексты — в `xml/ru/ru.xml` (UTF-8).

## Пятая локация — Город Майя

- `xml/locations/location_5.xml`, `location_5_quests.xml`; фоны `game/farms/location_5*.jpg` (обычный, дождь, солнце),
  `game/towns/location_5.jpg`, своя панель `game/stat_control_loc5`, комикс `location_5_comix`.
- Названия городов: Розмонт, Порт Эрроухед, Остров Хило, Долина Теней, Город Майя.
- Растения на продажу в 5-й локации: `spiral; bush; ice`.
- Новые растения (папка `vegetations`): ice, blue, bush, green, idol, red, spiral, yellow.
- Новые вредители: aura (аура-эффект), boar, frog, krot (с анимацией появления `arrive`), ladybird, lemur, parrot, turtle.

## Новые и изменённые механики (разделы, которых нет в первой игре)

| Раздел | Что видно в данных |
|--------|--------------------|
| `difficult` | две сложности: casual и hardcore (жизнь вредителей ×1,5, покупка ×1,3, продажа ×1,2, опыт ×2) |
| `combo_set` | серии ударов: урон ×1,0 → ×2,75 при 3…17 попаданиях подряд |
| `dropped_items` | из вредителей падают призы: опыт (5…30) и др., картинки `prize_items/` |
| `auto_bouquet_level` | автосборка букетов с уровнями (полоска прогресса на экране, пороги `80; 100`) |
| `bouquets` | букеты на 3, 4, 5 цветов; большие дороже (×1,15 и ×1,25) |
| `shop` | предметы фермы с уровнями и анимацией: сова (owl), часы (clock), рог (horn), алтарь, Нептун |
| колодец | три уровня колодца на локацию (`well_5`, `well_51`, `well_52`) |
| длина дня | `farm time / min_time / max_time / inc_time` — день растёт от min к max (в первой игре фиксированный `time`) |
| `aura`, `effects`, `particles` | ауры вредителей, частицы призов и продуктов |
| `trophy_room_screen` | комната трофеев: медали за букеты, убитых вредителей… (`trophy_room/`) |
| `tree/idol-tree-*` | дерево-идол (6 стадий) — вероятно, «цветок стихий» из названия |
| `quest_screen`, `select_quest_screen` | экран выбора квестов |
| `location_2…5_comix` | комиксы между локациями |
| `pause_screen`, `checkbox`, `tooltip`, `logo`, `highscores_difficult` | интерфейс |

- `skills.xml` вдвое больше (12 КБ против 6 КБ): 38 уровней вместо 36, пересмотрены значения.
- Квесты 2–4 локаций переписаны: файлы в 2–4 раза больше (например, `location_2_quests.xml` 48,7 КБ против 15,5 КБ).
- `items.xml`: 3,5 КБ против 0,6 КБ — больше предметов квестов.
